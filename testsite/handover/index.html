Forest handover experiment

An experiment, not a product. It asks one question: can two phones show they were together, in the browser, using only passkeys?

The seller's device runs this page. The buyer scans the QR code the browser shows, with their phone's camera, and confirms with Face ID or a fingerprint. Before that phone-to-phone flow finishes, the two devices must find each other over Bluetooth. Everything is recorded in this tab and nothing is sent anywhere. The steps for each test are in the test script.

1. Handover

The QR code appears in the browser's own window, not on this page. Confirm again asks the same phone to sign in with the passkey it just made; it shows another QR code.

2. Results

No handover yet.

3. Report

One report per test case: download it, then clear. The report keeps every try since the last clear, failures included. It is also kept in this browser, so a reload loses nothing.
